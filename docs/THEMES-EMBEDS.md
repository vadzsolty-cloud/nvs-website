# Világos téma és beágyazások

A tulajdonos kérésére világos/sötét témaváltó készült, a böngésző beállításából vett alapértékkel és helyben mentett választással.

A már kiválogatott Facebook-posztok hivatalos iframe beágyazásban jelennek meg. A videók oldalon belül indíthatók; hangos automatikus lejátszást nem erőltetünk. A Facebook bejelentkezéshez, régióhoz, nyilvánossághoz vagy beágyazási engedélyhez kötheti a megjelenítést. Minden elemnél megmarad az eredeti link. Nincs hozzáadott Pixel vagy Graph API token. Nem teljes automatikusan szinkronizált hírfolyam: a meglévő válogatott posztok aktuális Meta-tartalma töltődik be.

A Google-térkép közvetlen iframe src attribútummal, kattintás nélkül töltődik a meglévő műhelykoordinátákon. Az adatkezelési szöveg jelzi a külső szolgáltatók betöltését. A helyi CSP csak a Google Maps és a Facebook frame-jeit engedi.

Meta dokumentáció: https://developers.facebook.com/docs/plugins/embedded-video-player/
Google: https://developers.google.com/maps/documentation/embed/embedding-map

Foglalás DEMÓ; meglévő app és éles Firebase változatlan.
